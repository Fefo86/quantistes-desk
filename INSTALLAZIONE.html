Installazione su Hostinger

Il pacchetto contiene la build Next.js già compilata. Il sottodominio serve la piattaforma e WordPress autentica gli utenti registrati con il login che usano già.

File da usare

FileDestinazione
Quantistes-Hostinger.zipCartella pubblica del nuovo sito PHP
Quantistes-WordPress.zipAmministrazione WordPress di quantistes.pro
Quantistes-Sorgenti-Next.zipArchivio di sviluppo, da conservare sul computer

1. Crea il sottodominio

In hPanel apri Siti web → Aggiungi sito. Crea un sito PHP/HTML indipendente sul piano Cloud e assegna desk.quantistes.pro. Se il DNS è gestito altrove, aggiungi presso il relativo gestore il record A di desk con l’indirizzo IP indicato da Hostinger. Attendi che il certificato HTTPS risulti attivo. Guida Hostinger sui sottodomini

2. Attiva il collegamento WordPress

Accedi come amministratore a quantistes.pro. In Plugin → Aggiungi plugin → Carica plugin, scegli Quantistes-WordPress.zip, installa e attiva Quantistes Desk Access. Il plugin crea la tabella dei permessi temporanei e usa il login WordPress, inclusi i passaggi aggiuntivi gestiti dal tuo sito. Tutti i ruoli registrati possono entrare. Login nativo WordPress

3. Carica il desk

Apri il File Manager del nuovo sottodominio. Estrai Quantistes-Hostinger.zip nella sua document root vuota, di solito public_html. Dopo l’estrazione, index.php, .htaccess e private/ devono trovarsi direttamente nella radice. Se hPanel ha creato un file dimostrativo, conserva una copia fuori dalla document root e lasciala servire a index.php. Rimuovi lo ZIP caricato dalla cartella pubblica dopo l’estrazione.

Seleziona PHP 8.1 o successivo, con cURL, OpenSSL, zlib e sessioni abilitati. Escludi l’intero sottodominio desk dalla cache HTML condivisa e, se una regola personalizzata memorizza le risposte di WordPress, escludi /wp-admin/admin-post.php. Il gateway invia le intestazioni di cache privata. Attiva il reindirizzamento HTTPS in hPanel.

4. Verifica

  1. Apri https://desk.quantistes.pro/ in una finestra privata. Compare la pagina di accesso. Seleziona Accedi con WordPress e completa il login su quantistes.pro con un utente già registrato, anche un sottoscrittore.
  2. Il browser ritorna allo Scoreboard. Apri una sezione dal menu, usa Cerca strumento e prova un parametro nella seduta di archivio.
  3. Seleziona Esci dal desk. Una richiesta diretta a un file copiato dalla scheda Rete del browser deve ricevere 401 quando la sessione è chiusa. Il login WordPress sul sito principale mantiene il proprio ciclo di sessione.

Le credenziali vengono inserite sul dominio WordPress. Lo scambio server–server usa un codice monouso valido 90 secondi e una verifica PKCE. La sessione del desk dura al massimo otto ore. Il gateway ricontrolla la sessione WordPress entro 60 secondi alla richiesta successiva. I file aperti nel browser e gli import locali seguono il comportamento dell’applicazione originale.

Se scegli un nome diverso

Nel file private/config.php del sottodominio cambia desk_origin nell’origine HTTPS effettiva, senza barra finale. Se WordPress è installato in una sottocartella, imposta wp_endpoint sull’URL assoluto del suo wp-admin/admin-post.php. Nel wp-config.php di WordPress, prima del caricamento di wp-settings.php, aggiungi la stessa origine, ad esempio

define('QUANTISTES_DESK_ORIGIN', 'https://terminal.quantistes.pro');

Con desk.quantistes.pro e WordPress alla radice di quantistes.pro la configurazione è già pronta. Se un plugin di sicurezza limita admin-post.php ai soli amministratori, abilita per gli utenti del desk le azioni qdesk_authorize, qdesk_exchange, qdesk_session e qdesk_revoke.
